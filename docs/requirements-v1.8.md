v1.3では、自動補正を「誤差より大きい差が、条件のそろった記録で2回続いたとき」だけに絞った。記録が少ないうちは補正を控えめにする。カレンダーは、行ける曜日・時間帯と、時刻のある予定も見るようにした。入力で増えるのは、押さなくてもよい「いつもと違う」ボタン1つだけ。

**この版の読み方**：すべてのルールに次のどれかの印を付けている。

- **【論文】** 査読付き論文の結論が、その数字か範囲を支えている
- **【指針】** ACSMなどの運動指針の推奨値
- **【仮定】** 方向は論文と合うが、数字はアプリが決めたもの。設定で変えられる

v1.6から、アプリの画面とメモでは同じ印を読みやすい言葉で出す：【論文】→〔研究〕、【指針】→〔指針〕、【仮定】→〔目安〕（11.2）。この文書の中では、これまでどおり【論文】【指針】【仮定】と書く。

## 1. 概要

筋トレ・睡眠・疲労・筋肉痛の記録から、次のジムの日時・メニュー・重量を提案し、承認したらGoogleカレンダーに入れる。使うほど自分の実績に合わせて提案を直すが、直すのは同じ傾向が繰り返し出たときだけにする。

| 項目 | 内容 |  |
| --- | --- | --- |
| 目的 | 選んだ目的（やせたい・体力をつけたい・筋肉を大きくしたい・力を強くしたい・運動不足を解消したい、第12章）に合ったメニューを出し、回復させて、次のジムで良い状態で臨む |  |
| 利用者 | 自分ひとり（Googleアカウント1つ） |  |
| 使う端末 | スマホのブラウザ（縦画面・片手）。パソコンでも同じURLで使える |  |
| 作り方 | Google Apps ScriptのWebアプリ＋Googleスプレッドシート＋Googleカレンダー |  |
| 費用 | 0円。AIのAPIは使わず、計算も説明文も決めたルールで作る |  |

**やらないこと**

- 食事やサプリの助言、ケガの診断
- 種目の自動の入れ替え（メニューは目的ごとに本人が決め、初期値だけアプリが用意する）。v1.6のメニューA・Bの交互も、本人が決めた2つのメニューを順に出すだけで、種目をアプリが選ぶわけではない
- 筋肉の大きさの測定（測れないので、筋肥大は「刺激の量と続け方」で評価する。第5章）
- 心拍・HRV・挙上速度など、機器が要る測定
- 複数人での利用

## 2. v1.2の根拠の見直し

v1.2の「±3%で判定、1回の低下で補正」は、誤差より小さい差に反応していた。本物の1RMテストでも日によって中央値4.2%ぶれる \[34\]。そこに、RIRの予想のずれ（平均約1回）\[26\]が乗る。

### 2.1 ±3%の検証

推定1RMの式では、「限界までの回数」が1回ずれると値は次のように動く。

| 回数＋RIR | 1回のずれで動く幅 | 2回のずれで動く幅 |
| --- | --- | --- |
| 6（筋力向け） | 約2.8% | 約5.6% |
| 10 | 約2.5% | 約5.0% |
| 14（筋肥大向け） | 約2.3% | 約4.5% |

- ±3%は「RIRを約1回読み違えた」だけで超える。日々のぶれ（中央値4.2%）\[34\]よりも小さい
- だからv1.3では、判定の境目を「限界までの回数2回分」に広げ、さらに2回続けて出たときだけ補正する（第5章）
- 「2回分」「2回続けて」の数字そのものは【仮定】。ただし「誤差より大きい差だけを見る」「個人の傾向は繰り返し測って初めて分かる」という方向は、\[26\]\[33\]\[34\]と一致する

### 2.2 文献とルールの食い違い（v1.2で見つかったもの）

| v1.2の書き方 | 文献が実際に言っていること | v1.3での直し方 |
| --- | --- | --- |
| 上限までできた「1回」で増量【指針】\[8\] | ACSMは「目標を1〜2回超えるのが2回続いたら」 \[8\] | 「1回で増量」は【仮定】と書き直す。RIR不明のときは\[8\]どおり2回続けてから |
| 筋力向上で3〜5セット | ACSM 2026は1RMの約80%で2〜3セット \[23\] | 2〜3セットに直す |
| 「重量×(1+回数/30)」はベンチ・スクワットで精度が確かめられた \[32\] | 実際の1RMとの相関は高いが、デッドリフトでは低く出る \[32\] | 「同じ種目どうしの比較にだけ使う」と書き直す |
| 量が多いと回復が遅れる \[17\] | 高強度型と高ボリューム型で回復の仕方が違う \[17\] | 「8セットで+24時間」は【仮定】のまま、根拠の書き方を弱める |
| 推定1RMの低下でセットを減らす | 推定1RMは筋力の指標で、筋肥大の指標ではない \[9\]\[27\] | 筋肥大の評価は週のセット数と続け方で行う（5.5） |
| RIR未入力は「2」とみなす | 根拠なし | 「不明」として扱う（第3章） |

### 2.3 そのまま残すもの

回復の基本48〜72時間 \[1\]\[6\]\[17\]、補助の筋を0.5セットと数える方法 \[24\]、全身を週に2回以上 \[20\]\[23\]、筋肥大は週約10セット \[23\]、筋肥大の休憩2〜3分 \[28\]\[29\]、限界までは要らない \[23\]\[27\]、21日空いたら据え置き \[15\]\[16\]。

## 3. 入力項目

v1.2から増える入力は、押さなくてもよい「いつもと違う」ボタン1つだけ。前回の値が最初から入っているので、同じ内容なら1分以内で終わる。

| いつ | 入れるもの | 入れ方 |
| --- | --- | --- |
| ジムの後 | 種目、重量kg、セットごとの回数 | 前回の値から違うところだけ直す |
| ジムの後 | 最後のセットのRIR（あと何回できたか） | 種目ごとに 0・1・2・3・4以上 を押す。押さなければ「不明」 |
| ジムの後 | いつもと違う条件があった（任意） | 種目ごとのボタン1つ。フォームが崩れた、痛み、器具や順番が違う、時間がなかった、など |
| ジムの後 | 昨夜の睡眠時間、疲労感1〜5、筋肉痛1〜5 | ボタン。睡眠は0.5時間刻み |
| 次回の前日 | 昨夜の睡眠時間、疲労感1〜5、筋肉痛1〜5 | 省いても提案は出る |
| たまに | 体重、そのほかの運動 | 記録のみ |

「いつもと違う」を押した種目は、その日の結果を個人補正に使わない。フォームや痛みのせいで力が落ちた日を、「回復が足りない」と取り違えないため。フォームを自動で判定する方法はないので、本人の申告にする。

### 3.1 RIRが「不明」のとき

RIRを勝手に何かの数に置き換えない。RIRがなくてもできることは続け、RIRが要ることだけをやめる。

| 使うところ | RIRがあるとき | RIRが不明のとき |
| --- | --- | --- |
| 限界までやったか（回復の延長） | RIR 0 | 「回数の下限に届かないセットがあった」で代わりに判定する |
| 推定1RM | 計算する | 計算しない |
| 重量の提案 | 4.6の表どおり | 上限までできたのが2回続いたら+2.5%（ACSMの条件どおり \[8\]） |
| 回復の個人補正 | 使う | 使わない。連続の数も進めず、リセットもしない |
| 筋力の評価 | 使う | その日は飛ばす |
| 筋肥大の評価（週のセット数・続け方） | 使う | 使う（RIRは要らない） |

提案の理由には「RIR不明のため、増量は2回続けて上限までできたら」のように、何をやめたかを書く。

RIRは最後のセットだけにする（v1.2と同じ）。RIRは筋トレ用のきつさの尺度として作られ \[25\]、限界に近いほど予想が当たりやすい \[26\]。最後のセットは一番限界に近い。

- v1.6で9番目から下の23種目を足した（全部で31種目）。どの筋群に数えるかは【仮定】。腕の種目（カール・プレスダウン）は、腕だけの筋群を作らず「引く」「押す」に数える。ふくらはぎ（カーフレイズ）は「体の背面」に数える。4つの筋群で回復を数える仕組み（4.3）を変えないため
- 腹筋の種目は入れない。4つの筋群のどれにも当たらず、回復の計算に入らないため（「新しい種目を作る」でも主の筋群は必ず1つ選ぶ）

画面の「新しい種目を作る」で、主に使う筋群（1つ）と補助の筋群、自重かどうか、重さの刻みを決めて種目を足せる。

### 4.2 推定1RM

RIRが分かる日だけ、各種目の最後のセットから計算する。

```latex
\text{推定1RM} = \text{重量} \times \left(1 + \frac{\text{回数} + \text{RIR}}{30}\right)
```

- 実際の1RMとの相関は高いが、デッドリフトでは低めに出る \[32\]。だから同じ種目の過去の値と比べることにだけ使い、「あなたの1RMは○kg」とは表示しない
- 「回数＋RIR」を限界までの回数として式に入れるのは【仮定】
- 懸垂は「回数＋RIR」をそのまま指標にする

### 4.3 回復の推定

```latex
\text{回復の目安} = \text{その筋群を最後に鍛えた時刻} + \text{個人の基本時間} + \text{延長の合計}
```

個人の基本時間は最初48時間で、第5章の仕組みで48〜72時間の間でだけ動く。

| 延長の条件（その日の記録） | 延長 | 対象 | 根拠 |
| --- | --- | --- | --- |
| 限界までやった（RIR 0。RIR不明なら「下限に届かないセットがあった」） | +24時間 | その種目で主に使う筋群 | 方向 \[1\]【論文】、時間【仮定】 |
| その筋群の換算セット数が8以上 | +24時間 | その筋群 | \[17\]は量で回復が変わることだけ。「8」と時間は【仮定】 |
| ジムの後の疲労感が4以上 | +24時間 | 全部 | 方向 \[21\]【論文】、時間【仮定】 |
| ジムの後の筋肉痛が4以上 | +12時間 | 全部 | 筋肉痛は傷の大きさを表さない \[31\]。小さく扱う【仮定】 |
| 有酸素運動、年齢、体格 | 変えない | — | \[5\]\[22\]【論文】 |

- 合計は最大96時間まで【仮定】
- 表示は「約60時間（推定）」とし、「回復した」「回復していない」とは書かない

### 4.4 次回日

「毎回全身」なら前回鍛えた筋群のうち一番遅い回復の目安を、「上下交互」なら次にやる側の筋群の目安を使う。その時刻より後で、行ける曜日・時間帯に予定と重ならない空きがある日を探す（第6章）。週に2回以上になり、指針に合う \[20\]\[23\]【指針】。

## 5. 使うほど自分に合う仕組み

個人補正は、「条件のそろった記録で、誤差より大きい差が、続けて出たとき」だけ行う。動かすのは【仮定】の数字だけで、【論文】【指針】の範囲の外には出さない。

（図：回復時間の個人補正の流れ。判断は2つ。元の文書から写せなかったため省略）

「使える」の条件は5.1、「2回分」は5.2、延ばす幅は5.3で決める。

### 5.1 判定に使う記録

次をすべて満たす記録だけを使う。満たさない記録は、連続の数も進めず、リセットもしない。

- RIRが入っている
- 「いつもと違う」が押されていない（フォーム・痛みなど）
- 前夜の睡眠が6時間以上 \[30\]
- 前日チェックの疲労感が4未満（入れたとき）
- 前回から21日未満で、自分で重量を10%以上下げた日ではない

睡眠不足や疲労、フォームの乱れで力が落ちた日を、「回復時間が足りない」と取り違えないため。

### 5.2 1回ごとの判定

同じ種目の、直近の使える記録3回の推定1RMの中央値を「基準」にする。平均ではなく中央値にするのは、1回だけの外れ値に引っ張られないため。

| 判定 | 条件 |
| --- | --- |
| 低下 | 基準より「2回分」以上低い |
| 変化なし | 差が「2回分」未満 |
| 向上 | 基準より「2回分」以上高い |

```latex
\text{2回分} = \text{今回の重量} \times \frac{2}{30}
```

- 「2回分」は推定1RMで約4.5〜5.6%に当たる。RIRのずれ約1回 \[26\] と、日々のぶれ中央値4.2% \[34\] を上回る幅にした【仮定】
- 懸垂は「回数＋RIR」が2以上違うかで判定する
- 1回の「低下」だけでは何も変えない

### 5.3 記録の数で補正の強さを変える

個人の傾向は、繰り返し測って初めて誤差と区別できる \[33\]。そのため、使える記録が少ないうちは補正を控えめにする。区切りの回数は【仮定】。

| その種目の使える記録 | 段階 | 回復の基本時間を延ばす | 短くする |
| --- | --- | --- | --- |
| 3回未満 | 初期値のまま | しない | しない |
| 3〜7回 | 控えめ | +6時間 | しない |
| 8回以上 | 通常 | +12時間 | −6時間 |

### 5.4 回復の基本時間（筋群ごと）

- **延ばす**：同じ種目で「低下」が2回続いたら、その種目で主に使う筋群の基本時間を延ばす。間に「変化なし」か「向上」が入ったら数え直す
- **短くする**：「変化なし」か「向上」が3回続き、どれも回復の目安＋24時間以内に行った日なら、短くする。大きく空けた日の好調は、早く行けた証拠にならない
- 基本時間は48〜72時間に収める \[1\]\[6\]\[17\]【論文】。延ばす幅を短くする幅より大きくして安全側に寄せる【仮定】
- **72時間でも低下が2回続くとき**：それ以上は延ばさず、その筋群の主の種目を1セット減らす提案を出す（目的の下限まで）。休む時間より量の問題の可能性が高いため【仮定】
- 値を変えたら、その筋群の連続の数は0に戻す

### 5.5 種目ごとの増量の条件

- 初めは、上限までできた「1回」で増やす（4.6の5・6、【仮定】）
- 増やした直後に下限を割ったことが2回続けば、「2回続けて上限までできたら増やす」に切り替える。これはACSMの条件そのもの \[8\]【指針】
- 切り替え後に3回続けて増量がうまくいったら、「1回」に戻す【仮定】

### 5.6 目的ごとの評価

筋力と筋肥大は別の物差しで評価する。筋肉の大きさはこのアプリでは測れないので、筋肥大は「伸びたか」ではなく「刺激を足りるだけ続けられているか」を見る。評価は履歴画面に出すだけで、自動で変えるのは筋肥大のセット数の増加だけ。

| 目的 | 何を見るか | 表示 | 自動で変えるもの | 根拠 |
| --- | --- | --- | --- | --- |
| 筋力向上 | 種目ごとの推定1RM（4週間前の基準と今の基準）、同じ重量での回数 | 伸びている／横ばい／下がっている（境目は2回分） | なし（重量は4.6、5.5で変わる） | \[8\]\[23\] |
| 筋肥大 | 筋群ごとの週の換算セット数、直近4週の週あたりの回数、週の総負荷量（重量×回数の合計） | 刺激は足りている／足りない | 週のセット数が約10未満で、低下が続いていなければ、次回1セット増やす（目的の上限まで） | \[12\]\[20\]\[23\]\[24\] |
| 健康維持 | 直近4週の週あたりの回数 | 週に2回以上できているか | なし | \[20\]\[23\] |
| ダイエット（v1.7） | 体重の1週間の平均の変化、1週間の有酸素運動の合計分、直近4週の週あたりの回数 | 体重：減っている／横ばい／増えている。有酸素：目安150分に対して何分か | なし | \[20\]\[35\]、12.4 |
| 体力向上（v1.7） | 1週間の有酸素運動の合計分、同じ重さでの回数、直近4週の週あたりの回数 | 有酸素：目安150分に対して何分か。種目ごとに回数が伸びている／横ばい | なし | \[8\]\[20\]、12.4 |

- 推定1RMの低下は「疲労が残っているかもしれない」という合図として回復時間にだけ使い、「筋肥大の効果が落ちた」とは判断しない。軽い重量でも重い重量でも筋肥大は同程度起き、力の伸びとは一致しない \[9\]
- 週の総負荷量は参考として表示するだけ。筋肥大の物差しとしては、総負荷量よりセット数の方が調べられている \[12\]\[24\]

### 5.7 見える化とリセット

提案画面とメモに、個人の値とその段階を書く。例：「脚の前 約54時間（推定）・あなたの記録5回で調整ずみ」。設定画面に「個人の値を初期値に戻す」ボタンを置く。

## 6. Googleカレンダー連携

回復の目安を過ぎていて、行ける曜日・時間帯の中で、予定と重ならない空きがある時間を探し、候補を3つ出す。自分が1つ選んで「登録」を押したときだけ、時刻つきの予定を入れる。

### 6.1 設定（初期値つき）

| 設定 | 初期値 |
| --- | --- |
| 行ける曜日 | 月〜日のすべて |
| 行ける時間帯 | 平日 18:00〜22:00、土日 9:00〜21:00 |
| ジムにいる時間 | 90分 |
| 前後の余裕（移動など） | 30分 |
| 終日の予定がある日を避ける | はい |

### 6.2 候補の探し方

1. 「これより前には始めない時刻」＝4.4で決めた回復の目安
2. その日から順に、行けない曜日と、終日の予定がある日を飛ばす
3. その日の行ける時間帯から、時刻のある予定の時間を前後30分ずつ広げて取り除く
4. 残った空きのうち、90分入る一番早い時刻をその日の候補にする（1の時刻より後に限る）
5. 日付の違う候補が3つそろうか、28日先まで探したら止める。候補が0なら「空きが見つからない。曜日か時間帯の設定を見直してください」と出す

- 「予定」として数えるのは、自分のメインのカレンダーの予定のうち、「不参加」と答えた招待と、このアプリが入れた予定を除いたもの
- 28日の上限は、Apps Scriptの1回の実行時間とカレンダーの読み取り回数を抑えるため【仮定】

### 6.3 登録と変更

| 項目 | 仕様 |
| --- | --- |
| 登録のタイミング | 提案画面で候補を1つ選び、「登録」を押したときだけ |
| 予定の形 | 候補の時刻から90分の予定1件。アプリが入れた印を予定に付けておく |
| 予定の名前 | 「ジム（全身）」「ジム（上半身）」「ジム（下半身）」 |

| 登録後に別の予定が重なった | アプリを開いたときに「重なっています」と出し、新しい候補を見せる。自動では動かさない |

### 6.4 メモの書式

v1.6で書き方を変えた。ジムでスマホを開いてすぐ分かるよう、やること（メニュー）を一番上に置き、理由は下にまとめる。言葉の決まりは11.2。

```
【今日のメニュー】筋肥大・メニューA（上から順に）
1. スクワット 80kg × 8〜12回 × 3セット
　休憩2〜3分／最後のセットは、あと1〜2回できるところで止める
2. ベンチプレス 62.5kg × 8〜12回 × 3セット
　休憩2〜3分／最後のセットは、あと1〜2回できるところで止める

【今日のポイント】
・最後のセットは「あと1〜2回できる」ところで止める。回数かセットを少しずつ増やしていく 〔指針[23]〕

【体の状態（推定）】通常
・前日チェックでは、疲れの合図は見つかりませんでした

【前回からの変更】
・ベンチプレス：重さ 60→62.5kg
```

## 11. メニューの追加・分かりやすい文・名言（v1.6）

### 11.1 メニューAとBを交互に

**なぜ2つにするか**：1回のジムの種目を増やすと、ジムにいる時間（90分、6.1）に収まらない。そこで1回の量は変えずに、メニューを2つ持って交互にやる。同じ筋肉を別の種目でも鍛えられ、種目に変化をつけることは指針でもすすめられている \[8\]【指針】（方向）。AとBを1回ずつ交互にするやり方は【仮定】。

**次がAかBかの決め方**

1. メニューBに種目がない（「なし」）か、種目の一覧にある種目が1つもないときは、いつもA
2. 最後のジムで、「Aにだけある種目」と「Bにだけある種目」のどちらを多くやったかを数える（AとBの両方にある種目は数えない）
3. Aの方が多ければ次はB、Bの方が多ければ次はA
4. 同じ数なら、1つ前のジムで同じように数える。記録がなければA
5. 上下交互（4.4）のときは、次にやる側（上半身か下半身）の種目と、同じ側の最後のジムだけで数える

- 本人が記録画面で種目を足したり外したりしても、実際にやった種目で数えるので、交互がずれない
- 重さは種目ごとに、その種目の前回の記録から決める（4.6）。Bの日のあいだAの種目は休むので、21日以上空かない限り、次のAの日はAの前回の記録の続きになる
- 前回やってBの日にやらない種目は、「前回から変えたところ」に「メニューAの種目なので、今回はお休み（次のAの日にやります）」と出す
- 種目を外して足りなくなったとき（10.3の「補う」）は、AとBの両方と、ほかの目的のメニューから探す

**設定**：`menu_hyp`・`menu_str`・`menu_hlt`（メニューA）と `menu_hyp_b`・`menu_str_b`・`menu_hlt_b`（メニューB）。画面の「目的ごとのメニュー」でAとBを切り替えて編集する。Aは1種目以上必要、Bは空にでき、空のときは設定シートに「なし」と入る。

### 11.2 分かりやすい文の決まり

**文の形**：「前回どうだったか → だから今回どうするか → 根拠の印」の順に、短く書く。

| 使わない言葉 | 代わりの書き方 |
| --- | --- |
| RIR 2 | 最後のセットは、あと2回できた |
| RIR 0 | 最後のセットは限界までやった |
| RIR不明 | あと何回できたかは未記入 |
| 目標RIR 1〜2（あと1〜2回残す） | あと1〜2回できるところで止める |
| 余裕を1回多く残す | いつもより1回早めに止める |
| 換算セット | セット数（補助で使った分は半分で数える） |
| 筋群 | 筋肉、部位 |
| 回復の目安（推定）より前 | まだ回復の途中（推定） |
| 回復の目安を過ぎている | もう回復している（推定） |
| 「低下」の判定 | 調子が落ちていた |
| 停滞 | 伸びていない（停滞）、伸び悩んでいる |
| 【論文】【指針】【仮定】（文の途中） | 文の最後に 〔研究[4][30]〕〔指針[8]〕〔目安〕 |

**例**

- v1.5：「前回60kgで12・12・12回、RIR 2 → +2.5kg（2.5%を2.5kg刻みに丸め）。幅は【指針】[8]、1回で増やすのは【仮定】」
- v1.6：「前回は60kgで12・12・12回（最後のセットは、あと2回できた）。全部のセットで12回できたので、2.5kg重くします（60→62.5kg）。〔指針[8]〕」

**根拠の印は消さない**。ルールを科学的根拠で決め、どこが論文でどこがアプリの決めた数字かを分かるようにする方針（「この版の読み方」）は変えない。言葉を短くして、置く場所を文の最後にそろえただけ。印の意味は、提案画面の下とメモの最後に毎回書く。

**並べ方**：提案画面は「体の状態 → いつ行く？ → 今日のポイント → 今日のメニュー → 前回から変えたところ → 部位ごとの回復」（7.2）。種目ごとのくわしい理由は「なぜ？」を押したときだけ開き、最初に目に入る文を少なくする。カレンダーのメモはメニューを一番上に置く（6.4）。

**直さないもの**：履歴画面の判定の文字（「使わない（RIR不明）」など）と、設定シートの項目名。判定の文字は筋トレ記録シートに書き残す値で、前の版の記録とそろえるため。

### 11.3 名言（スポーツ選手の名言250個）

- 初期値の名言を、ことわざ・偉人の言葉20個から、スポーツ選手の名言250個に入れ替える。登録のたびに1つをくじで選んでメモの最後に書く（6.4）

- 発言者は「名前（競技）」と書く。出どころは、場面がはっきりしているもの（例：2023年WBC決勝前の声出し、2019年の引退会見）だけ書く
- 海外の選手の言葉は日本語に訳したもので、意訳を含む
- 選ばなかったもの：ジムでのやる気につながりにくいもの（冗談・その場の発言）、ドーピング問題のある選手のもの
- **確認の深さ**：発言者は広く知られている名前で載せたが、1つずつ原典（インタビュー記事・本）では確かめていない。中には、本人の言葉として広まっているが元は別の人の言葉だったり、広告の文だったりするものがありうる。間違いが分かったら「種目と名言」シートで直すか消す
- 名言は計算に使わないので、間違っていても提案の内容は変わらない

### 12.2 新しい2つの目的の数字と根拠

**やせたい（ダイエット）**

- 体を動かす量が週150〜250分だと、体重が増えるのは防げるが、減るのは少し。週250分を超えると、体重がはっきり減ることと関係している \[35\]【指針】
- 筋トレは、それだけでは体重を減らす効果を高めないが、筋肉（脂肪以外の体の重さ）を増やし、脂肪を減らすのを助けることがある \[35\]【指針】
- そこで、筋トレ（全身の大きな筋肉を週2回 \[20\]\[23\]）＋ジムの最後の有酸素運動（12.3）＋ジムの外の運動（歩く・走るなど）で、1週間の合計を目安と比べる
- 筋トレの回数・セット数・休憩は、健康維持と同じ（10〜15回・2〜3セット・1〜2分）にした。体重を減らすための筋トレの回数を決めた指針は見つけていないので、この数字は【仮定】
- 食事の助言はしない（第1章「やらないこと」）。メモと評価の画面には「体重を減らすには食事も大切です。このアプリは食事の助言はしません」とだけ書く

**体力をつけたい（体力向上）**

- 筋肉の持久力（何回も続けられる力）には、軽め〜中くらいの重さ（1RMの40〜60%）で回数を多く（15回より多く）、休憩を短く（90秒未満）する \[8\]【指針】。初期値は15〜20回・休憩1〜1.5分（下限の15回は、指針の「15回より多く」の境目に合わせて丸めた【仮定】）
- セット数（2〜3）と止めどころ（あと2〜3回）は【仮定】
- 全身の持久力のために、有酸素運動も入れる（12.3）。目安は週150分 \[20\]【指針】
- 推定1RMの式（4.2）は10回以下の回数で調べられたもので \[32\]、15〜20回では誤差が大きくなりうる。同じ種目どうしの比べにだけ使うのは変えないが、体力向上では評価を「同じ重さでの回数」で見る（12.4）

### 12.3 有酸素運動

| 項目 | 仕様 |

| 出す場所 | メニューの最後（筋トレのあと）。「有酸素運動 20〜30分（バイク・早歩きなど）」 |
| 強さの書き方 | 「会話はできるけれど、歌うのはきついくらい」（中くらいの強さの目安。言い方は【仮定】） |
| 時間の初期値 | 20〜30分（設定 `fat_cardio`・`end_cardio`）。90分のジムに収まる長さ【仮定】 |
| 体の状態で変える | やや疲れ → 20分（下限）、強い疲れ・休養をすすめる → 10分か、やらない（10.2の状態を使う）【仮定】 |

### 12.4 目的ごとの評価（5.6に追加）

**体重（やせたいのとき）**

- 直近7日の体重の平均と、その前の7日の平均を比べる。どちらの7日にも体重の記録が2回以上あるときだけ判定し、足りなければ「記録不足（週に2回以上、体重を記録してください）」
- 差が−0.2kg以下なら「減っている」、+0.2kg以上なら「増えている」、それ以外は「横ばい」【仮定】
- 1日ずつではなく平均で見るのは、毎日の体重が水分や食事で上下するため【仮定】
- 評価は見せるだけで、メニューや重さは自動で変えない

**回数（体力をつけたいのとき）**

- 種目ごとに、同じ重さで1セットあたりの回数が4週間前より増えたかを見る（伸びている／横ばい）

## 13. 前回の内容から次回の種目を選ぶ・種目を直す（v1.8）

### 13.1 種目の選び方

メニューA（基本）とメニューB（入れかえ候補）を合わせたものを「候補」とし、毎回つぎの順で選ぶ。種目の数はメニューAの数。

1. 部位（押す・引く・脚の前・体の背面）ごとに、次のジムの日までの1週間の換算セット数を数え、目安までの不足を出す。目安は、筋肥大は週10セット【指針】[23]、ほかの目的は「週2回（`weeklyGroupDays`）×目的のセット数の下限」【指針】[20]
2. AとBの両方に入れた種目は「毎回やる種目」として最初に入れる
3. 不足の大きい部位から、その部位を主に使う種目を1つずつ入れる（全身の大きな筋群を週2回以上【指針】[20]）
4. 残りの枠は、不足を一番多く埋める種目から入れる（1種目＝目的のセット数の下限で数える）
5. 前回やった種目は、同じ部位の別の種目が候補にあれば点を下げる（種目に変化をつける【指針】[8]。下げ幅0.5は【仮定】）
6. 並びはそれぞれのメニューの中の順番（大きい種目を上に書く）
7. そのあと、これまでどおり体の状態に合わせた調整（第10章）をする

Bが「なし」のときは候補＝Aなので、v1.7と同じくAの種目になる。入れた理由（あと何セット足りない／前回の○○の代わり／毎回やる種目）と外した理由を「前回から変えたところ」とメモに書く。

### 13.2 画面

- 提案画面のいちばん上に「前回やった内容」（保存した記録）を出す
- 「今日のポイント」「今日のメニュー」を「次回のポイント」「次回のメニュー」にする（カレンダーのメモは、その日に見るので「今日のメニュー」のまま）

### 13.3 種目を直す・消す

- 「種目を作る・直す」で種目をえらぶと、名前・自重かどうか・主に使う筋肉・補助の筋肉・刻みを直せる
- 名前を変えたら、筋トレ記録・メニュー・疲れやすい組の名前も変える
- 消すと、メニューと疲れやすい組からも外す。記録は残す。メニューAの最後の1種目は消せない
- 重りありの種目で重さ0の記録（自重として記録したもの）は、重さの提案と個人補正に使わない

### 13.4 カレンダーで消した予定

`getEventById` はゴミ箱の予定も返すため、その時間の予定の一覧に同じIDがあるか確かめる。無ければ提案シートの状態を「カレンダーで消された」にし、次の登録で新しい予定を作る。
